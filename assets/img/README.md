# Photos

Déposer ici les photos du club, puis renseigner leur chemin dans `assets/js/data.js` (bloc `photos`).

Noms conseillés :
- `hero.jpg` : grande photo de la page d'accueil (format paysage, 2000 px de large environ)
- `club.jpg` : photo de groupe ou de dojo (section « Un club de quartier »)
- `judo.jpg`, `karate.jpg`, `aikido.jpg`, `krav-maga.jpg`, `boxe-francaise.jpg`, `boxe-thai.jpg`,
  `kick-boxing.jpg`, `handi-judo.jpg`, `fitness-fighting-move.jpg`, `tai-chi-chuan.jpg` (format 4:3)
- photos des professeurs (format carré), référencées par nom dans `photos.teachers`

Tant qu'une photo vaut `null`, un bloc sombre s'affiche à sa place.
